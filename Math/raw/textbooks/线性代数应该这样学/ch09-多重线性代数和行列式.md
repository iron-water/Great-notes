# 双线性型

?? 上的一个双线性型是一个从 $V \times V$ 到 $\mathbf { F }$ 的函数 $\beta ( \cdot , \cdot )$ ，它在两个位置上分别是线性的，意即如果我们固定任意一个位置中的向量，那么就会得到另一个位置上的线性函数．正式的定义如下

# 9.1 定义：双线性型（bilinear form）

?? 上的一个双线性型是一个函数 $\beta : V \times V \to \mathbf { F }$ ，该函数满足，对于所有 $u \in V$ ，

$$
v \mapsto \beta (v, u) \quad {\text {与}} \quad v \mapsto \beta (u, v)
$$

都是 $V$ 上的线性泛函

例如，若 $V$ 是实内积空间，那么将有序对 $( u , \nu ) \in V \times V$ 对应到 $\langle u , \nu \rangle$ 的函数就是 $V$ 上的双线性型．若 $V$ 是非零复内积空间，那么这个函数就不是双线性型，因为内积在第二个位置上不是线性的（第二个位置上的复数被提出时会变为其复共轭）

回忆一下，上述定义中使用的术语“线性泛函”，意为映射至标量域 F 的线性函数．因而，术语“双线性泛函”比“双线性型”与之更具有一致性．不幸的是，后者已经成为标准用法了

若 ${ \textbf { F } } = { \textbf { R } }$ ，那么双线性型与内积的不同之处在于，内积需要具备对称性【意即对所有$\nu , w \in V$ ， $\beta ( \nu , w ) = \beta ( w , \nu ) \mid$ 】和正定性【意即对所有 $\nu \in V \backslash \{ 0 \}$ ， $\beta ( \nu , \nu ) > 0$ 】，但是双线性型不需要具备这些性质

设 $e _ { 1 } , \ldots , e _ { n }$ 是 $V$ 的基．那么映射 $\beta \mapsto { \mathcal { M } } ( \beta )$ 是将 $V ^ { ( 2 ) }$ 映成 $\mathbf { F } ^ { n , n }$ 的同构．此外， $\dim V ^ { ( 2 ) } =$ $( \dim V ) ^ { 2 }$ ．

$$
\beta_ {A} \left(x _ {1} e _ {1} + \dots + x _ {n} e _ {n}, y _ {1} e _ {1} + \dots + y _ {n} e _ {n}\right) = \sum_ {k = 1} ^ {n} \sum_ {j = 1} ^ {n} A _ {j, k} x _ {j} y _ {k}
$$

（若 $V = \mathbf { F } ^ { n }$ 且 $e _ { 1 } , \ldots , e _ { n }$ 是 $\mathbf { F } ^ { n }$ 的标准基，那么该 $\beta _ { A }$ 就与例 9.2 中第二例所给出的双线性型 $\beta _ { A }$ 相同）

从 $V ^ { ( 2 ) }$ 到 $\mathbf { F } ^ { n , n }$ 的线性映射 $\beta \mapsto { \mathcal { M } } ( \beta )$ 和从 $\mathbf { F } ^ { n , n }$ 到 $V ^ { ( 2 ) }$ 的线性映射 $A \mapsto \beta _ { A }$ 是彼此的逆，这是因为，对所有 $\beta \in V ^ { ( 2 ) }$ 皆有 $\beta _ { \mathcal { M } ( \beta ) } = \beta$ ，且对所有 $A \in \mathbf { F } ^ { n , n }$ 皆有 $\mathcal { M } ( \beta _ { A } ) = A$ （你应自行验证）

# 9.6 双线性型与算子的复合

设 $\beta$ 是 $V$ 上的双线性型， $T \in { \mathcal { L } } ( V )$ ．定义 $V$ 上的双线性型 $\alpha$ 和 $\rho$ 为

$$
\alpha (u, v) = \beta (u, T v) \quad {\text {与}} \quad \rho (u, v) = \beta (T u, v).
$$

令 $e _ { 1 } , \ldots , e _ { n }$ 是 $V$ 的基．那么

$$
\mathcal {M} (\alpha) = \mathcal {M} (\beta) \mathcal {M} (T) \quad \text {且} \quad \mathcal {M} (\rho) = \mathcal {M} (T) ^ {\mathrm {t}} \mathcal {M} (\beta).
$$

证明 若 $j , k \in \{ 1 , \ldots , n \}$ ，则

$$
\begin{array}{l} \mathcal {M} (\alpha) _ {j, k} = \alpha \left(e _ {j}, e _ {k}\right) \\ = \beta \left(e _ {j}, T e _ {k}\right) \\ = \beta \left(e _ {j}, \sum_ {m = 1} ^ {n} \mathcal {M} (T) _ {m, k} e _ {m}\right) \\ = \sum_ {m = 1} ^ {n} \beta \left(e _ {j}, e _ {m}\right) \mathcal {M} (T) _ {m, k} \\ = \left(\mathcal {M} (\beta) \mathcal {M} (T)\right) _ {j, k}. \\ \end{array}
$$

于是 $\mathcal { M } ( \alpha ) = \mathcal { M } ( \beta ) \mathcal { M } ( T )$ ．类似可证 $\mathcal { M } ( \rho ) = \mathcal { M } ( T ) ^ { \mathnormal { \mathrm { t } } } \mathcal { M } ( \beta )$

下面结论展示了当基改变时，双线性型的矩阵如何变化．下面结论中的公式应与算子的矩阵的换基公式（见3.84）比照看待．两个公式是类似的，区别在于下面公式中含转置 $C ^ { \mathrm { t } }$ ，而算子的矩阵的换基公式中含逆 $C ^ { - 1 }$

# 9.7 换基公式（change-of-basis formula）

设 $\beta \in V ^ { ( 2 ) }$ ．设 $e _ { 1 } , \ldots , e _ { n }$ 和 $f _ { 1 } , \ldots , f _ { n }$ 是 $V$ 的基．令

$$
A = \mathcal {M} \big (\beta , (e _ {1}, \ldots , e _ {n}) \big) \quad \text {且} \quad B = \mathcal {M} \big (\beta , (f _ {1}, \ldots , f _ {n}) \big)
$$

以及 $C = \mathcal { M } \big ( I , ( e _ { 1 } , . . . , e _ { n } ) , ( f _ { 1 } , . . . , f _ { n } ) \big )$ ．那么

$$
A = C ^ {\mathrm {t}} B C.
$$

证明 线性映射引理（3.4）告诉我们，存在算子 $T \in { \mathcal { L } } ( V )$ 使得 $T f _ { k } = e _ { k }$ 对每个 $k = 1 , \ldots , n$ 成立．由算子关于一基的矩阵的定义可得

$$
\mathcal {M} \left(T, \left(f _ {1}, \dots , f _ {n}\right)\right) = C.
$$

定义 $V$ 上的双线性型 $\alpha , \rho$ 为

$$
\alpha (u, v) = \beta (u, T v) \quad {\text {与}} \quad \rho (u, v) = \alpha (T u, v) = \beta (T u, T v).
$$

那么对所有 $j , k \in \{ 1 , \ldots , n \}$ 均有 $\beta ( e _ { j } , e _ { k } ) = \beta ( T f _ { j } , T f _ { k } ) = \rho ( f _ { j } , f _ { k } )$ ．于是

$$
\begin{array}{l} A = \mathcal {M} \left(\rho , \left(f _ {1}, \dots , f _ {n}\right)\right) \\ = C ^ {t} \mathcal {M} (\alpha , (f _ {1}, \dots , f _ {n})) \\ = C ^ {t} B C, \\ \end{array}
$$

其中第二、三行都源自9.6

定义 $\mathcal { P } _ { 2 } ( \mathbf { R } )$ 上的双线性型 $\beta$ 为 $\beta ( p , q ) = p ( 2 ) \cdot q ^ { \prime } ( 3 )$ ．令

$$
