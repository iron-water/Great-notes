# 与D指导的问答篇

Q: 東雲正樹的线代老师说"矩阵就是一张数表"，他一开始鄙夷这个说法，后来又认为这是对的。你觉得他在中间**经历了什么**才改变了看法？用自己的话说说。

A: 我认为重点在于矩阵的同构问题。
東雲正樹一开始证明了线性空间里面的 Schwartz 不等式，也就是说在线性空间里面有比较好的性质。
之后就是同构问题，流程如下
```
研究对象
  ⬇️
具有向量形式、构成线性空间 ➡️ 引入矩阵这张数表
  ⬇️                     ⬇️
具有比较好的性质、定义了内积  具有列矩阵（和行矩阵）
  ⬇️                     ⬇️
可以抽象出正交基──────────────规定矩阵乘法
                         ⬇️
                     使得列矩阵的集合和正交基的集合同构
```

可见这里矩阵并没有进入线性空间，而是作为一个外挂在线性变换外的一个具有特殊乘法定义的数表。它负责把这里的线性空间用更简洁深刻的方式来进行研究，也方便计算机的处理。
