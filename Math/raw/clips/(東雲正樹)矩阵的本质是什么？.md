矩阵本质上就是张定义了 **加减乘** 与 **数乘** 运算的数表, 这里说的矩阵不仅仅是那些方块儿, 还包括那些横着竖着的长条儿阵. 就是被你们称为行向量与列向量的那些东西, 其实都是行矩阵或列矩阵.

这堆规格各异的表格之间能进行一些极为明确的数学运算, 这也是让很多人 XJB 学了一学期却完全不知道自己到底在干嘛的东西, 这里就不展开了. 总之就是, 有了看得见摸得着的形体与运算规律后, 矩阵对我们来说就已经是一套可靠的数学工具了.

于是接下来的重点就是线性空间与同构映射这俩概念.

## \*懒得看, 你最好是给我长话短说版\*

总结下来就是, 我们平时研究的事物时常会构成一个线性空间, 然而直接在这些线性空间里运算很不方便, 我们就转之跑到与这个线性空间同构的行或列矩阵空间里计算. 然后算完了可以得到一些数或一些矩阵, 我们就再用逆同构映射射回原来的空间里以得到相应的数、矢量或算符.

有时我们所研究的线性空间可能正好就是现实的时空点所构成的空间, 于是空间中相应的线性变换就会对应到具体的时空操作. 在现实时空射到列矩阵空间的那个同构映射下时空点就对应到列矩阵, 而线性变换或者说所谓的时空操作则会对应到一个方阵^[更严谨来说空间点到列矩阵的同构映射与线性变换到方阵的同构映射并不是同一个映射, 因为定义域不同, 不过这里不分那么细也没啥, 你懂我意思就行了. ].

 **故矩阵只是通过同构映射来帮助研究线性空间的一些定义了加减数乘与乘法的数表罢了, 仅此而已.** 

而所谓的取一个表示可以被认为就是将所研究的数学对象的集合同态映射到确定矩阵集合的过程.

## \*详细版\*

## 什么事线性空间?

线性空间即对元素定义了矢量加法与数乘这两个能满足八条确定运算规律的集合, 而对于集合中的元素我们就称之为矢量. 更详细的定义可参考本回答的 **附录 A** .

举个例子, 你高中做立体几何时接触到的三维欧几里得空间就是线性空间, 原点到空间中每一个点的箭头都构成一个矢量, 于是也可以说这个空间就是由这些箭头构成的. 那理论上你完全可以就把这些箭头打包带走拿去研究, 毕竟它们已经包含了三维空间的所有信息了嘛. 就是说你实际处理这个三维空间的时候并不需要真去将这个三维空间画出来, 而真正参与运算的只是纸面上那些矢量的代数式, 这也是我们能在二维的纸上解三维题目的原因, 而这些三维矢量的运算大家都是很清楚了的. 所以就完全可以说三维欧几里得空间就是这些三维矢量配合它们的加法与数乘所构成的集合.

定义了加法与数乘后我们可以在线性空间里证明出很多有用的结论, 但我们通常还会引入内积这个概念, 因为你纯粹线性空间的玩儿法太少了. 所谓内积其本质是一个映射 `!$\left\langle \cdot \ ,\cdot  \right\rangle :V\times V\to 数域$` , 而定义了内积的线性空间就能升格为内积空间. 更详细的定义可参考本回答的 **附录 B** .

比如说三角不等式: 对任意矢量  `!$a,b$`  一定有  `!$\left| a \right|+\left| b \right|\ge \left| a+b \right|.$` 

 **证明如下:**  \*你假装能看懂就行, 目的就只是想表达一下这个过程超妈抽象. \*

首先需要用到 Schwartz 不等式:  `!$\left\langle a,a \right\rangle \left\langle b,b \right\rangle \ge \left\langle a,b \right\rangle \left\langle b,a \right\rangle .$` 

那就要先证明 Schwartz 不等式:

-   构造  `!$c=b-\frac{\left\langle a,b \right\rangle }{{{\left| a \right|}^{2}}}a$`  再利用公理  `!${{\left| c \right|}^{2}}\ge 0$`  可以得到:
-    `!${{\left| c \right|}^{2}}=\left\langle b-\frac{\left\langle a,b \right\rangle }{{{\left| a \right|}^{2}}}a,b-\frac{\left\langle a,b \right\rangle }{{{\left| a \right|}^{2}}}a \right\rangle $` 
-    `!$\ \ \ \ \ ={{\left| b \right|}^{2}}-\left\langle b,a \right\rangle \frac{\left\langle a,b \right\rangle }{{{\left| a \right|}^{2}}}-\left\langle a,b \right\rangle \frac{{{\left\langle a,b \right\rangle }^{*}}}{{{\left| a \right|}^{2}}}+\frac{{{\left\langle a,b \right\rangle }^{*}}\left\langle a,b \right\rangle }{{{\left| a \right|}^{2}}{{\left| a \right|}^{2}}}\left\langle a,a \right\rangle \ge 0.$` 
-     
    然后利用关系  `!${{\left| a \right|}^{2}}>0$`  ^[注意这里不允许等于 0, 自己想想吧, 不解释了. ]得到:
-    `!$\ \ \ \ \ {{\left| a \right|}^{2}}{{\left| b \right|}^{2}}-\left\langle b,a \right\rangle \left\langle a,b \right\rangle -\left\langle a,b \right\rangle {{\left\langle a,b \right\rangle }^{*}}+{{\left\langle a,b \right\rangle }^{*}}\left\langle a,b \right\rangle \ge 0$` 
-    `!$\Rightarrow {{\left| a \right|}^{2}}{{\left| b \right|}^{2}}-\left\langle a,b \right\rangle {{\left\langle a,b \right\rangle }^{*}}\ge 0$` 
-    `!$\Rightarrow {{\left| a \right|}^{2}}{{\left| b \right|}^{2}}\ge \left\langle a,b \right\rangle \left\langle b,a \right\rangle $` , done.

然后要知道对任意复数  `!$z$`  恒有  `!$\operatorname{Re}z\le \left| z \right|$`  我们就得到:

-    `!$\ \ \ \ \sqrt{\left\langle a+b,a+b \right\rangle }$` 
-    `!$=\sqrt{\left\langle a,a \right\rangle +\left\langle b,b \right\rangle +\left\langle a,b \right\rangle +\left\langle b,a \right\rangle }$` 
-    `!$=\sqrt{\left\langle a,a \right\rangle +\left\langle b,b \right\rangle +2\operatorname{Re}\left\langle a,b \right\rangle }\le \sqrt{\left\langle a,a \right\rangle +\left\langle b,b \right\rangle +2\left| \left\langle a,b \right\rangle  \right|}.$`   
    
-   利用 Schwartz 不等式  `!${{\left| a \right|}^{2}}{{\left| b \right|}^{2}}\ge \left\langle a,b \right\rangle \left\langle b,a \right\rangle ={{\left| \left\langle a,b \right\rangle  \right|}^{2}}\Rightarrow \left| a \right|\left| b \right|\ge \left| \left\langle a,b \right\rangle  \right|.$`   
    
-   于是就有  `!$\left| a+b \right|=\sqrt{\left\langle a+b,a+b \right\rangle }$` 
-    `!$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \le \sqrt{\left\langle a,a \right\rangle +\left\langle b,b \right\rangle +2\left| \left\langle a,b \right\rangle  \right|}$` 
-    `!$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \le \sqrt{\left\langle a,a \right\rangle +\left\langle b,b \right\rangle +2\left| a \right|\left| b \right|}=\sqrt{{{\left( \left| a \right|+\left| b \right| \right)}^{2}}}=\left| a \right|+\left| b \right|.$` 

Done.

## 什么是同构映射?

同构映射就是能所有保持运算性质都一一对应的映射. 对于两个有确定运算的集合, 如果里面的元素能一一对应, 然后元素之间的运算还能保持完全相同的结构, 那其实纯数学上来看, 这俩集合在这对运算下就没有任何区别了. 我们就会称这俩集合在这对运算下同构.

比如说有人在集合  `!$\left\{ F,G,H \right\}$`  与集合  `!$\left\{ f,g,h \right\}$`  上分别定义了封闭的乘法.

一一对应肯定是有的, 比如我们可以这样对应:

 `!$F\leftrightarrow f,G\leftrightarrow g,H\leftrightarrow h,$` 

即建立一个映射  `!$\phi $`  满足  `!$\phi \left( F \right)=f,\phi \left( G \right)=g,\phi \left( H \right)=h$` . 但这还不足以达到同构, 因为这俩集合还有一个额外的乘法结构. 如果这个一一对应的映射能办到像下面这样:

 `!$\phi \left( FGF\cdots HG \right)=\phi \left( F \right)\phi \left( G \right)\phi \left( F \right)\cdots \phi \left( H \right)\phi \left( G \right)=fgf\cdots hg.$` 

使得乘积的映射等于映射的乘积, 那就说明这个  `!$\phi $`  是个同构映射, 而存在同构映射的集合就同构.

因为能保证运算结果的映射等于映射后进行相应运算的结果, 所以这俩集合就不再仅仅只是元素的个数相同然后存在元素的一一对应那么简单了, 而是整个集合的结构或者说元素之间的关系都完全相同, 所以才会将这种情形命名为同构.

比如说  `!$\{A,B,C\}$`  作为基矢张成了一个定义了内积的线性空间, 而  `!$\{a,b,c\}$`  做基矢张成了另一个定义了内积的线性空间. 我们可以建立映射  `!$\phi \left( A \right)=a,\phi \left( B \right)=b,\phi \left( C \right)=c$` , 如果这个映射能类似于像下面这样:

-    `!$\phi \left( 3A+2B\left\langle A,5C+A \right\rangle  \right)=3\phi \left( A \right)+2\phi \left( B \right)\left\langle \phi \left( A \right),5\phi \left( C \right)+\phi \left( A \right) \right\rangle $` 
-    `!$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \,=3a+2b\left\langle a,5c+a \right\rangle .$` 

满足所有可能的运算关系之间的对应, 那这俩内积空间也就同构了.

当然如果  `!$\phi \left( A \right)=a,\phi \left( B \right)=b,\phi \left( C \right)=c$`  行不通而  `!$\varphi \left( A \right)=c,\varphi \left( B \right)=a,\varphi \left( C \right)=b$`  却能满足  `!$\varphi \left( 3A+2B\left\langle A,5C+A \right\rangle  \right)=3\varphi \left( A \right)+2\varphi \left( B \right)\left\langle \varphi \left( A \right),5\varphi \left( C \right)+\varphi \left( A \right) \right\rangle $`  的话那这俩内积空间就也还是同构的, 只要存在一个同构映射就行了.

 **同构有啥好处呢?** 

数学上来说, 在某组运算下同构的俩集合其实就可以在这组运算下看做同一个数学对象了, 因为它们在这组运算下的结构完全一样, 而数学只在乎结构.

## 那么重点就来了

生产生活中, 我们其实并不会直接用到矩阵对吧?

但在生产生活中我们要碰到很多能相互作用的事物, 而有时候这些事物的集合与相互作用的形式都会正好满足线性空间的定义, 比如说在力学中力这个概念就满足线性空间的定义, 在立体几何中那些向量箭头也满足线性空间的定义, 而量子力学中的态空间也正好满足线性空间的定义··· 呃有些倒反天罡了, 另外计算机学科中也有相应的数组, 然后就算是在设计领域、金融领域之类的也··· 反正只要提到了矢量或者向量之类的字眼时, 就一定有个啥构成了线性空间.

然后呢? 构成了线性空间之后, 空间内的东西就获得了一个新的名称——矢量.

但这些矢量就像猫猫狗狗花花草草一样, 虽然可以定义明确的运算, 但也很难运算.

光看我前面废了老劲儿证明的 Schwartz 不等式与三角不等式应该就体会到这一点了.

 **接着我们就发明了这样一些数表, 赋予了它们明确的加减乘与数乘等运算, 然后又称之为矩阵.** 

然后你会发现所有同型号的列矩阵在矩阵的运算下正好能满足定义构成一个线性空间甚至内积空间. 再然后呢? 不用我说你也该猜到了吧?

 **再然后就是同构:** 

一个空间定义了内积, 其内部矢量就有了正交的概念, 于是可以选出一组正交基  `!$\left\{ {{e}_{1}},{{e}_{2}},\cdots ,{{e}_{n}} \right\}$`  去表达空间内的任何一个矢量.

然后你会发现列阵集合  `!$\left\{ \left[ \begin{matrix}    1  \\    0  \\    \vdots   \\    0  \\ \end{matrix} \right],\left[ \begin{matrix}    0  \\    1  \\    \vdots   \\    0  \\ \end{matrix} \right],\cdots ,\left[ \begin{matrix}    0  \\    0  \\    \vdots   \\    1  \\ \end{matrix} \right] \right\}$`  所张成的空间正好能和上面的那个同构.

也就是存在 **同构映射**   `!$\phi \left( {{e}_{1}} \right)=\left[ \begin{matrix}    1  \\    0  \\    \vdots   \\    0  \\ \end{matrix} \right],\phi \left( {{e}_{2}} \right)=\left[ \begin{matrix}    0  \\    1  \\    \vdots   \\    0  \\ \end{matrix} \right],\cdots ,\phi \left( {{e}_{n}} \right)=\left[ \begin{matrix}    0  \\    0  \\    \vdots   \\    1  \\ \end{matrix} \right].$` 

然后所有的原内积空间中的运算就都归结为列矩阵之间的运算了.

而矩阵的运算就是你们 XJB 学了一学期的内些玩意儿, 是十分清晰的, 也很适合交给计算机.

 **那矩阵是啥?** 

方阵右乘列阵会得到另一个列阵, 所以方阵是列阵到列阵的映射.

而在线性空间上有线性变换这么个概念, 指的是将空间中的一个矢量映射到另一个矢量的过程.

矢量在同构映射下得到列阵, 所以能将列阵映射到列阵的方阵被逆同构映射射回原来的内积空间时会对应到线性空间上的一个线性变换.  **这就是为啥有人会说矩阵就是线性变换** , 但现在看来这个说法其实非常蠢或者说非常幼稚对吧? 矩阵就只是矩阵啊, 为啥要跟线性变换绑定起来?

 **所以为啥矩阵的乘法要搞得那么别扭?** 

答案可以是为了能与线性空间的运算构成同构关系, 但你也可以说就是这么定义的, 定义就没那么多为什么, 这才是学数学该有的精神.

## 回到梦开始的地方

如果你研究的空间正好是四维时空, 那么四维时空中的时空点作为矢量就构成了个线性空间, 而这个线性空间中的线性变换, 确实可以说是时空的一个旋转拉伸或者啥的, 也就是一个时空操作.

然后这个线性空间会与列或行矩阵空间同构, 于是时空操作在同构映射下确实会对应到一个矩阵.

 **但你说矩阵是啥呢?** 

于是矩阵就事什么几把时空操作了吗? 不对吧··· 你不觉得这逻辑很荒唐吗?

 **矩阵本质上来说就只是一张定义了明确的加减数乘与乘法的数表罢了.**

## 那啥是表示呢?

对于表示这个概念你可以认为它是一个同态映射的过程.

-   所谓同态映射就是没那么严格的同构映射, 当然我这么说很不严谨，，
-   同构映射是保持了运算关系或者说集合结构的 **一一对应** .
-   而同态映射则是保持了运算关系或者说集合结构的 **多一对应** .
-   听不懂也是没有办法的事, 你可以去搜一下我写的群论 note, 这里就不比比赖赖了.

在数学中时常会定义一些有明确运算关系的抽象符号构成的集合, 比如说群或者什么什么代数. 它们满足的运算关系是十分明确的, 但很抽象, 因为这些符号的本体看不见摸不着.

如果我们能找到一组矩阵构成的集合与上面那些抽象符号构成的集合正好同态, 那这组矩阵在相应的同态映射下就被称为这些抽象符号的表示矩阵. 而采用同态映射的过程就是一个选取表示的过程, 如果同态映射升格到同构映射那这就构成了所谓的忠实表示, 因为它同构了呗, 它们在数学意义上是一回事了, 也就没有信息丢失, 所以曰之忠实.

 **总而言之这样将一组抽象的数学对象对应到矩阵的做法就被称为选取一个表示.** 

而这里的表示矩阵所作用到的列矩阵们构成的线性空间就被称为表示空间.

所以也老有人会喜欢说出类似于「群就是矩阵构成的集合」,「代数就是矩阵构成的集合」这样让人听了浑身难受的说法, 这些说法就和说「线性变换就是矩阵」一样是很恶心人的··· 当然你要再给它反过来说什么「矩阵就是线性变换」那我是真的就更我他妈的··· 哎.

确实, 在同构映射或者忠实表示下, 这些矩阵和你研究的数学对象完全等价.

所以你就可以不区分二者了吗? 我是说你电脑产生的信号和你显示器发出来的电磁波还同构呢, 那你还买条毛的显示器呢? 你主机的本质不就已经是显示器了吗?

你将群定义为它的其中一个忠实表示, 那群元岂不是平白无故地就多出了加法与数乘?

所以说不需要的信息就全砍掉, 抽象符号的定义就是最简洁也是最美的.

但是很遗憾, 为了让新手尤其是物理人新手能更舒服点儿, 我的群论 notes 也还是采取了所谓的定义表示与矩阵李群的概念··· 其实最优美的做法还是从具有群结构的流形出发, 但写那种东西, 在一般通过的物理人看来你只是在自嗨罢了. 不过好在绕个弯子从矩阵群入手搞明白了再退一步回到抽象的群本身也完全是可以理解的, 就是说虽然保住了结果但过程确实没那么优美了.

哎··· 形式、美与正义总是要付出代价的.
