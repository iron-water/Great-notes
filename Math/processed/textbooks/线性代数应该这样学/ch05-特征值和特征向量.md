# 第5章 特征值和特征向量

由一个向量空间到另一个向量空间的线性映射是第3章的研究对象．现在我们开始研究算子，也就是由一个向量空间到其本身的线性映射．对于算子的研究构成了线性代数中最为重要的组成部分

为了研究一个算子，我们尝试将其限制在一个更小的子空间中．讨论将该算子限制于什么样的子空间内能使其仍为算子，将引导我们得到不变子空间的概念．每个一维不变子空间，都产生于一个这样的向量——它被该算子映射为自身的标量倍．沿着这条研究路径，我们就会得出特征向量和特征值的概念

接着，我们将证明线性代数中最为重要的结论之一：非零有限维复向量空间上的每个算子都有特征值．这条结论使我们得以证明，对于有限维复向量空间上的每个算子，都存在该向量空间的一个基，使得该算子关于该基的矩阵至少有近一半的元素等于0

# 5.5 定义：特征值（eigenvalue）

设 $T \in { \mathcal { L } } ( V )$ ．对于数 $\lambda \in \mathbf { F }$ ，若存在 $\nu \in V$ 使得 $\nu \neq 0$ 且 $T \nu = \lambda \nu$ ，则称 $\lambda$ 为 $T$ 的特征值

在上面定义中，我们要求 $\nu \neq 0$ ，因为每个标量 $\lambda \in \mathbf { F }$ 都满足 $T 0 = \lambda 0$

上面的讨论表明， $V$ 有在 $T$ 下不变的一维子空间，当且仅当 $T$ 有特征值

# 5.19 特征值的存在性

非零有限维复向量空间上的每个算子都有特征值

证明 设 $V$ 是有限维复向量空间，其维数 $n > 0$ ， $T \in { \mathcal { L } } ( V )$ ．取 $\nu \in V$ 且 $\nu \neq 0$ ．那么

$$
v, T v, T ^ {2} v, \dots , T ^ {n} v
$$

不是线性无关的，因为 $V$ 的维数是 $n$ ，该组的长度却是 $n + 1$ ．因此上述向量的某个线性组合（其中各系数不全为0）会等于向量0．于是，存在次数最小的非常值多项式 $p$ 使得

$$
p (T) v = 0.
$$

根据代数基本定理的版本一（见 4.12），存在 $\lambda \in \mathbf { C }$ 使得 $p ( \lambda ) = 0$ ．所以，存在多项式$q \in \mathcal { P } ( \mathbf { C } )$ 使得

$$
p (z) = (z - \lambda) q (z)
$$

对每个 $z \in \mathbf { C }$ 都成立（见4.6）．由此可得（利用 5.17）

$$
0 = p (T) v = (T - \lambda I) (q (T) v).
$$

因为 $q$ 的次数小于 $p$ 的次数，所以我们可知 $q ( T ) \nu \neq 0$ ．于是上述等式就表明?? 是 $T$ 的一个特征值， $q ( T ) \nu$ 是对应于它的特征向量

上述证明的关键是运用代数基本定理．习题 16 后的注记有助于解释为何代数基本定理与上述结论结合得如此紧密

上述结论中的 $\mathbf { F } = \mathbf { C }$ 这个假设不能替换为 $\mathbf { F } = \mathbf { R } \mathbf { \mathrm { . } }$ ——从例 5.9 可看出．下例则说明，上述结论中的“有限维”这个假设也不能去掉

# 5.22 最小多项式的存在性、唯一性和次数

设 $V$ 是有限维的， $T \in { \mathcal { L } } ( V )$ ．那么存在唯一的次数最小的首一多项式 $p \in { \mathcal { P } } ( \mathbf { F } )$ ，使得$p ( T ) = 0$ ．此外， $\deg p \leq \dim V$

证明 若 $\dim V = 0$ ，那么 $I$ 就是 $V$ 上的零算子，从而我们取 $p$ 为常值多项式1即可

现在对 $\dim V$ 用归纳法，于是假设 $\dim V > 0$ 且欲证结论对于所有维数更小的向量空间上的所有算子都成立．设 $u \in V$ （ $u \ne 0$ ）．组 $u , T u , \dots , T ^ { \dim V } u$ 的长度为 $1 + \dim V$ ，因而是线性相关的．根据线性相关性引理（2.19），存在最小正整数 $m \leq \dim V$ 使得 $T ^ { m } u$ 是 $u , T u , \dots , T ^ { m - 1 } u$ 的线性组合．于是存在标量 $c _ { 0 } , c _ { 1 } , c _ { 2 } , \dotsc , c _ { m - 1 } \in { \bf F }$ 使得

$$
c _ {0} u + c _ {1} T u + \dots + c _ {m - 1} T ^ {m - 1} u + T ^ {m} u = 0. \tag {5.23}
$$

定义首一多项式 $q \in \mathcal { P } _ { m } ( \mathbf { F } )$ 为

$$
q (z) = c _ {0} + c _ {1} z + \dots + c _ {m - 1} z ^ {m - 1} + z ^ {m}.
$$

那么式 (5.23) 就表明 $q ( T ) u = 0$

若 $k$ 为非负整数，那么

$$
q (T) \left(T ^ {k} u\right) = T ^ {k} \left(q (T) u\right) = T ^ {k} (0) = 0.
$$

线性相关性引理（2.19）表明， $u , T u , \dots , T ^ { m - 1 } u$ 线性无关，于是由上式可得 dim null $q ( T ) \geq m$ 因此

$$
\dim \operatorname {r a n g e} q (T) = \dim V - \dim \operatorname {n u l l} q (T) \leq \dim V - m.
$$

因为 range $q ( T )$ 在 $T$ 下是不变的（由 5.18），所以我们可以将归纳假设应用于 range $q ( T )$ 上的算子 $T | _ { \mathrm { r a n g e } q ( T ) }$ ，从而存在首一多项式 $s \in { \mathcal { P } } ( \mathbf { F } )$ 使得

$$
\deg s \leq \dim V - m \quad {\text {且}} \quad s (T | _ {\mathrm {r a n g e} q (T)}) = 0.
$$

因此，对于所有 $\nu \in V$ ，我们有

$$
\big ((s q) (T) \big) (v) = s (T) \big (q (T) v \big) = 0,
$$

这是因为 $q ( T ) \nu \in$ range $q ( T )$ 且 $s ( T ) | _ { \mathrm { r a n g e } q ( T ) } = s ( T | _ { \mathrm { r a n g e } q ( T ) } ) = 0$ ．于是 ???? 是满足 $\deg s q \leq \dim V$ 和 $( s q ) ( T ) = 0$ 的首一多项式

上段表明，存在次数不高于 $\dim V$ 的首一多项式，其作用于 $T$ 可得算子0．于是，作用于$T$ 得到算子0的次数最小的首一多项式存在，这就完成了本结论存在性部分的证明

令 $p \in { \mathcal { P } } ( \mathbf { F } )$ 是使 $p ( T ) = 0$ 成立的次数最小的首一多项式．为证明本结论的唯一性部分，设$r \in { \mathcal { P } } ( \mathbf { F } )$ 是次数与 $p$ 相同的首一多项式，且 $r ( T ) = 0$ ．那么 $( p - r ) ( T ) = 0$ 且 $\deg ( p - r ) < \deg p$ 若 $p - r$ 不等于0，那么将 $p - r$ 除以其最高次项的系数，可得一个作用于 $T$ 会得到算子0的首一多项式（且其次数小于 $p$ 的次数）．于是 $p - r = 0$ ，即唯一性得证 ■

# 5.24 定义：最小多项式（minimal polynomial）

设 $V$ 是有限维的，且 $T \in { \mathcal { L } } ( V )$ ．那么 $T$ 的最小多项式是唯一使得 $p ( T ) = 0$ 成立的次数最小的首一多项式 $p \in { \mathcal { P } } ( \mathbf { F } )$

为计算一个算子 $T \in { \mathcal { L } } ( V )$ 的最小多项式，我们需要求出使得

$$
c _ {0} I + c _ {1} T + \dots + c _ {m - 1} T ^ {m - 1} = - T ^ {m}
$$

有解 $c _ { 0 } , c _ { 1 } , \dotsc , c _ { m - 1 } \in \mathbf { F }$ 的最小正整数 $m$ ．如果我们选取 $V$ 的一个基，再将上述方程中的 $T$ 换成 $T$ 的矩阵，那么可以将上述方程看成有 $( \dim V ) ^ { 2 }$ 个方程、 $m$ 个未知数 $c _ { 0 } , c _ { 1 } , \dotsc , c _ { m - 1 } \in \mathbf { F }$ 的线性方程组．要知道解是否存在，我们用高斯消元法或者线性方程组的其他快速解法，对$m = 1 , 2 , \ldots$ 诸值依次作检验，直到发现有解即可．由5.22，对于某个最小的正整数 $m \leq \dim V$ ，上述方程组有解．那么 $T$ 的最小多项式就是 $c _ { 0 } + c _ { 1 } z + \cdot \cdot \cdot + c _ { m - 1 } z ^ { m - 1 } + z ^ { m }$

更快（且更常用）的做法是，选取 $\nu \in V$ （ $\nu \neq 0$ ）并考虑方程

$$
c _ {0} v + c _ {1} T v + \dots + c _ {\dim V - 1} T ^ {\dim V - 1} v = - T ^ {\dim V} v. \tag {5.25}
$$

利用 $V$ 的一个基，将上述方程转化为有 $\dim V$ 个方程、 $\dim V$ 个未知数 $c _ { 0 } , c _ { 1 } , \ldots , c _ { \dim V - 1 }$ 的线性方程组．若该方程组有唯一解 $c _ { 0 } , c _ { 1 } , \ldots , c _ { \dim V - 1 }$ （这是最常出现的情况），那么标量 $c _ { 0 } , c _ { 1 } , \ldots$ ,$c _ { \dim V - 1 }$ , 1 就是 $T$ 的最小多项式的各系数 （因为 5.22 指出最小多项式的次数最多是 $\dim V$ ）

考虑 $\mathbf { R } ^ { 4 }$ 上的算子（可看成关于标准基的$4 \times 4$ 矩阵），运用上段方法并取 $\boldsymbol { \nu } = ( 1 , 0 , 0 , 0 )$

此处的百分比估计值基于对数百万个随机 的矩阵的实测

对于由区间 [−10,10] 上的整数构成的 $4 \times 4$ 矩阵，此法适用于其中超过 $9 9 . 8 \%$ 的矩阵；而对于由区间 [−100,100] 上的整数构成的 $4 \times 4$ 矩阵，此法适用于其中超过 $9 9 . 9 9 9 \%$ 的矩阵

# 5.33 偶数维的零空间

设 $\mathbf { F } = \mathbf { R }$ 且 $V$ 是有限维的，并设 $T \in { \mathcal { L } } ( V ) , b , c \in \mathbf { R }$ 使得 $b ^ { 2 } < 4 c$ ．那么 dim nul $( T ^ { 2 } { + } b T { + } c I )$ 是偶数

证明 回忆一下，由 5.18， $\mathrm { n u l l } ( T ^ { 2 } + b T + c I )$ 在 $T$ 下是不变的．将 $V$ 替换成 $\mathrm { n u l l } ( T ^ { 2 } + b T + c I )$ 并将 $T$ 替换成限制在 $\mathrm { n u l l } ( T ^ { 2 } + b T + c I )$ 上的 $T$ ，我们便可认为 $T ^ { 2 } + b T + c I = 0$ ，这样一来，我们需证明的就是 $\dim V$ 为偶数．3

设 $\lambda \in \mathbf { R }$ 及 $\nu \in V$ 满足 $T \nu = \lambda \nu$ ．那么

$$
0 = (T ^ {2} + b T + c I) v = (\lambda^ {2} + b \lambda + c) v = \left(\left(\lambda + \frac {b}{2}\right) ^ {2} + c - \frac {b ^ {2}}{4}\right) v.
$$

上式最外层括号中的数是个正数．于是上式表明 $\nu = 0$ ．因此我们证明了 $T$ 没有特征向量

令 $U$ 是 $V$ 的一个子空间，它在 $T$ 下是不变的，并且，所有在 $T$ 下不变且维数为偶的 $V$ 的子空间中，它具有最大的维数．若 $U = V$ ，那么我们的证明完成了；否则，设存在某个 $w \in V$ 满足 $w \not \in U$

令 $W = \mathsf { s p a n } ( w , T w )$ ．那么 $W$ 在 $T$ 下不变，因为 $T ( T w ) = - b T w - c w$ ．另外， $\dim W = 2$ 否则 $w$ 就会成为 $T$ 的特征向量．这样一来，

$$
\dim (U + W) = \dim U + \dim W - \dim (U \cap W) = \dim U + 2,
$$

其中 $U \cap W = \{ 0 \}$ ，否则 $U \cap W$ 就会成为 $V$ 的一个 1 维子空间且在 $T$ 下不变（这是不可能的，因为 $T$ 没有特征向量）

因为 $U + W$ 在 $T$ 下不变，所以上述等式表明，存在在 $T$ 下不变、维数为偶且大于 $\mathrm { d i m } U$ 的$V$ 的子空间．于是， $U \neq V$ 的假设不正确．因此， $V$ 的维数为偶数 ■

接下来这条结果指出，奇数维的向量空间上的每个算子都有特征值．我们已知此结论对于复向量空间成立（且无需奇数维的假设）．于是在下面的证明中，我们将假设 $\mathbf { F } = \mathbf { R }$

# 5.34 奇数维向量空间上的算子总有特征值

奇数维向量空间上的每个算子都有特征值

证明 设 $\mathbf { F } = \mathbf { R }$ 且 $V$ 是有限维的．令 $n = \dim V$ ，并设 $n$ 为奇数．令 $T \in { \mathcal { L } } ( V )$ ．为证明 $T$ 有特征值，我们对 $n$ 用步长为 2 的归纳法．首先，注意到若 $\dim V = 1$ ，那么欲证结论成立，因为这样的话 $V$ 中的每个向量都是 $T$ 的特征向量

现在，假设 $n \geq 3$ 且欲证结论对于维数小于 $n$ 的所有奇数维向量空间上的所有算子都成立令 $p$ 表示 $T$ 的最小多项式．若对于某 $\lambda \in \mathbf { R }$ ， $p$ 是 $x - \lambda$ 的多项式倍，那么 $\lambda$ 是 $T$ 的一个特征值【由 5.27 (a)】，证明就完成了．于是我们可设存在 $b , c \in \mathbf { R }$ 使得 $b ^ { 2 } < 4 c$ 且 $p$ 是 $x ^ { 2 } + b x + c$ 的多项式倍（见 4.16）

从而，存在首一多项式 $q \in { \mathcal { P } } ( \mathbf { R } )$ 使得 $p ( x ) = q ( x ) ( x ^ { 2 } + b x + c )$ 对所有 $x \in \mathbf { R }$ 成立．这样一来，就有

$$
0 = p (T) = \left(q (T)\right) \left(T ^ {2} + b T + c I\right),
$$

由此， $q ( T )$ 等于 range $( T ^ { 2 } + b T + c I )$ 上的算子 0．因为 $\deg q < \deg p$ 且 $p$ 是 $T$ 的最小多项式，所以上式表明 range $( T ^ { 2 } + b T + c I ) \neq V .$

线性映射基本定理（3.21）告诉我们

$$
\dim V = \dim \operatorname {n u l l} \left(T ^ {2} + b T + c I\right) + \dim \operatorname {r a n g e} \left(T ^ {2} + b T + c I\right).
$$

因为 $\dim V$ 是奇数（由命题假设）且dim null $( T ^ { 2 } + b T + c I )$ 是偶数（由5.33），所以上式就说明dim range $( T ^ { 2 } + b T + c I )$ 是奇数

所以，range $( T ^ { 2 } + b T + c I )$ 是 $V$ 的在 $T$ 下不变的子空间（由5.18），其维数为奇且小于 $\dim V$ 这样一来，由我们的归纳假设可得，限制于range $( T ^ { 2 } + b T + c I )$ 的算子 $T$ 有特征值，也即 $T$ 有特征值 ■

# 5.35 定义：算子的矩阵（matrix of an operator）、M (??)

$$

其中的元素 $A _ { j , k }$ 定义为

T v _ {k} = A _ {1, k} v _ {1} + \dots + A _ {n, k} v _ {n}.
$$

若根据上下文无法明确看出选取哪个基，就用 $M ( T , ( \nu _ { 1 } , \ldots , \nu _ { n } ) )$ 这个记号

若 $T$ 是 $\mathbf { F } ^ { n }$ 上的算子，且未明确基的选取，那么就假定所取的基是标准基（其中第 $k$ 个

# 5.37 定义：矩阵的对角线（diagonal of a matrix）

方阵的对角线由从它的左上角到右下角的直线上的元素所构成

# 5.38 定义：上三角矩阵（upper-triangular matrix）

称一个方阵为上三角矩阵，若其中所有在对角线之下的元素都是 0

例如，上面所示的 $3 \times 3$ 矩阵就是上三角矩阵

我们一般将上三角矩阵表示成下面的形式

$$
\left( \begin{array}{c c c} \lambda_ {1} & & * \\ & \ddots & \\ 0 & & \lambda_ {n} \end{array} \right),
$$

上述矩阵中的0表示在这个 $n \times n$ 矩阵中，在对角线之下的元素都等于0．可以认为上三角

我们常用 $^ *$ 来表示矩阵中那些我们未知的，或与正在讨论的问题无关的元素

矩阵是相当简单的——若 $n$ 很大，那么在 $n \times n$ 上三角矩阵中至少有将近一半的元素都是0

下面结论在上三角矩阵和不变子空间之间建立了有用的联系

# 5.39 上三角矩阵的条件

设 $T \in { \mathcal { L } } ( V )$ 且 $\nu _ { 1 } , \ldots , \nu _ { n }$ 是 $V$ 的一个基．那么下面几条结论等价

(a) $T$ 关于 $\nu _ { 1 } , \ldots , \nu _ { n }$ 的矩阵是上三角矩阵  
(b) 对每个 $k = 1 , \ldots , n$ ，均有 span $\left( \nu _ { 1 } , \ldots , \nu _ { k } \right)$ 在 $T$ 下不变   
(c) 对每个 $k = 1 , \ldots , n$ ，均有 $T \nu _ { k } \in \operatorname { s p a n } \left( \nu _ { 1 } , \ldots , \nu _ { k } \right)$

证明 先设 (a) 成立．为证明 (b) 成立，设 $k \in \{ 1 , \ldots , n \}$ ．若 $j \in \{ 1 , \ldots , n \}$ ，那么

$$
T v _ {j} \in \operatorname {s p a n} \left(v _ {1}, \dots , v _ {j}\right),
$$

这是因为 $T$ 关于 $\nu _ { 1 } , \ldots , \nu _ { n }$ 的矩阵是上三角矩阵．因为若 $j \leq k$ 则 spa $\begin{array} { r } { \mathfrak { n } ( \nu _ { 1 } , \dots , \nu _ { j } ) \subseteq \operatorname { s p a n } ( \nu _ { 1 } , \dots , \nu _ { k } ) , } \end{array}$ 所以我们可知，对每个 $j \in \{ 1 , \ldots , k \}$ ，有

$$
T v _ {j} \in \operatorname {s p a n} \left(v _ {1}, \dots , v _ {k}\right).
$$

于是， $\operatorname { s p a n } ( \nu _ { 1 } , \dots , \nu _ { k } )$ 在 $T$ 下不变，这就证明了 (a) 蕴涵 (b)

现在设 (b) 成立，因此对每个 $k = 1 , \ldots , n$ ，均有 $\operatorname { s p a n } ( \nu _ { 1 } , \dots , \nu _ { k } )$ 在 $T$ 下不变．特别地，对每个 $k = 1 , \ldots , n$ ，均有 $T \nu _ { k } \in \operatorname { s p a n } ( \nu _ { 1 } , \ldots , \nu _ { k } )$ ．于是 (b) 蕴涵 (c)

现在设 (c) 成立，因此对每个 $k = 1 , \ldots , n$ ，均有 $T \nu _ { k } \in \operatorname { s p a n } ( \nu _ { 1 } , \ldots , \nu _ { k } )$ ．这就意味着，当用基向量 $\nu _ { 1 } , \ldots , \nu _ { n }$ 的线性组合来表达 $T \nu _ { k }$ 时，我们只需用到向量 $\nu _ { 1 } , \ldots , \nu _ { k }$ ．因此， $M ( T )$ 对角线之下的所有元素都是 0．于是， $M ( T )$ 是个上三角矩阵，这就证明了 (c) 蕴涵 (a)

我们证明了 $( \mathbf { a } ) \implies ( \mathbf { b } ) \implies ( \mathbf { c } ) \implies ( \mathbf { a } )$ ，也就证明了 (a)、(b) 和 (c) 是等价的

下面结论告诉我们，若 $T \in { \mathcal { L } } ( V )$ ，且关于 $V$ 的某个基的矩阵是

$$
\mathcal {M} (T) = \left( \begin{array}{c c c} \lambda_ {1} & & * \\ & \ddots & \\ 0 & & \lambda_ {n} \end{array} \right)
$$

那么 $T$ 满足一个依赖于 $\lambda _ { 1 } , \ldots , \lambda _ { n }$ 的简单等式

# 5.40 具有上三角矩阵的算子满足的等式

设 $T \in { \mathcal { L } } ( V )$ 且存在 $V$ 的一个基，使得 $T$ 关于该基有上三角矩阵，且该矩阵的对角线元素是 $\lambda _ { 1 } , \ldots , \lambda _ { n }$ ，那么

$$
(T - \lambda_ {1} I) \dots (T - \lambda_ {n} I) = 0.
$$

证明 令 $\nu _ { 1 } , \ldots , \nu _ { n }$ 是 $V$ 的一个基，且 $T$ 关于该基有对角线元素为 $\lambda _ { 1 } , \ldots , \lambda _ { n }$ 的上三角矩阵那么 $T \nu _ { 1 } = \lambda _ { 1 } \nu _ { 1 }$ ，这意味着 $( T - \lambda _ { 1 } I ) \nu _ { 1 } = 0$ ，由此可推出 $( T - \lambda _ { 1 } I ) \cdot \cdot \cdot ( T - \lambda _ { m } I ) \nu _ { 1 } = 0$ 对于$m = 1 , \ldots , n$ 成立（利用各 $T - \lambda _ { j } I$ 和各 $T - \lambda _ { k } I$ 的可交换性可得）

注意到 $( T - \lambda _ { 2 } I ) \nu _ { 2 } \in \mathfrak { s p a n } ( \nu _ { 1 } )$ ．于是 $( T - \lambda _ { 1 } I ) ( T - \lambda _ { 2 } I ) \nu _ { 2 } = 0$ （根据上段可得），并可由此推出 $( T - \lambda _ { 1 } I ) \cdot \cdot \cdot ( T - \lambda _ { m } I ) \nu _ { 2 } = 0$ 对于 $m = 2 , \ldots , n$ 成立（利用各 $T - \lambda _ { j } I$ 和各 $T - \lambda _ { k } I$ 的可交换性可得）

注意到 $( T - \lambda _ { 3 } I ) \nu _ { 3 } \in \mathrm { s p a n } ( \nu _ { 1 } , \nu _ { 2 } )$ ．于是由上段可得， $( T - \lambda _ { 1 } I ) ( T - \lambda _ { 2 } I ) ( T - \lambda _ { 3 } I ) \nu _ { 3 } = 0$ ，并可由此推出 $( T - \lambda _ { 1 } I ) \cdot \cdot \cdot ( T - \lambda _ { m } I ) \nu _ { 3 } = 0$ 对于 $m = 3 , \ldots , n$ 成立（利用各 $T - \lambda _ { j } I$ 和各 $T - \lambda _ { k } I$ 的可交换性可得）

按照这个方式继续下去，我们就会发现对每个 $k = 1 , \ldots , n$ 都有 $( T - \lambda _ { 1 } I ) \cdot \cdot \cdot ( T - \lambda _ { n } I ) \nu _ { k } = 0$ 于是 $( T - \lambda _ { 1 } I ) \cdot \cdot \cdot ( T - \lambda _ { n } I )$ 是0算子，因为它把 $V$ 的一个基中所有向量都对应至 0 ■

由算子的矩阵确切计算出算子的特征值的方法并不存在，这实为憾事．然而，如果我们有幸找到一个基，使得算子关于该基的矩阵是上三角的，那么特征值的计算问题就变得很平凡，如下面结论所示

# 5.41 由上三角矩阵确定特征值

设 $T \in { \mathcal { L } } ( V )$ 关于 $V$ 的某个基有上三角矩阵．那么?? 的特征值恰为该上三角矩阵对角线上的各元素

$$

因为 $T \nu _ { 1 } = \lambda _ { 1 } \nu _ { 1 }$ ，我们可见 $\lambda _ { 1 }$ 是 $T$ 的一个特征值

设 $k \in \{ 2 , \ldots , n \}$ ．那么 $( T - \lambda _ { k } I ) \nu _ { k } \in \mathrm { s p a n } ( \nu _ { 1 } , \dots , \nu _ { k - 1 } )$ ．于是 $T - \lambda _ { k } I$ 将 $\operatorname { s p a n } ( \nu _ { 1 } , \dots , \nu _ { k } )$ 映射至 $\operatorname { s p a n } ( \nu _ { 1 } , \ldots , \nu _ { k - 1 } )$ ．又因为

# 5.66 定义：格什戈林圆盘（Gershgorin disks）

设 $T \in { \mathcal { L } } ( V )$ 且 $\nu _ { 1 } , \ldots , \nu _ { n }$ 是 $V$ 的一个基．令 $A$ 表示 $T$ 关于该基的矩阵 $T$ 关于基 $\nu _ { 1 } , \ldots , \nu _ { n }$ 的格什戈林圆盘是形如

$$
\left\{z\in \mathbf{F}:|z - A_{j,j}| \leq \sum_{\substack{k = 1\\ k\neq j}}^{n}|A_{j,k}|\right\}
$$

的集合，其中 $j \in \{ 1 , \ldots , n \}$

因为上面定义中的 $j$ 有 $n$ 种取值，所以 $T$ 有 $n$ 个格什戈林圆盘．若 $\mathbf { F } = \mathbf { C }$ ，那么对每个$j \in \{ 1 , \ldots , n \}$ ，与之对应的格什戈林圆盘就是 C 中以 $A _ { j , j }$ 为圆心的闭圆盘，其中 $A _ { j , j }$ 是 $A$ 的对角线上的第 $j$ 个元素．这个闭圆盘的半径，等于 $A$ 的第 $j$ 行除对角线上的元素外各元素绝对值之和．若 $\mathbf { F } = \mathbf { R }$ ，那么格什戈林圆盘是 $\mathbf { R }$ 中的闭区间

在上述方阵 $A$ 为对角阵的特殊情况下，每个格什戈林圆盘都仅包含一个点，即 $A$ 的对角线上的元素（进而 $T$ 的每个特征值都是这样的点，这也是下面结论所保证的）．下面的结论有个推论：如果 $A$ 的非对角线元素很小，那么 $T$ 的每个特征值都与 $A$ 的对角线上的一个元素很接近

# 5E 可交换算子

# 5.71 定义：可交换（commute）

对于同一向量空间上的两个算子 $S$ 和 $T$ ，若 $S T = T S$ ，则它们可交换  
对于两个大小相同的方阵 $A$ 和 $B$ ，若 $A B = B A$ ，则它们可交换

例如，若 $T$ 是算子， $p , q \in { \mathcal { P } } ( \mathbf { F } )$ ，那么 $p ( T )$ 和 $q ( T )$ 可交换【见 5.17 (b)】

又例如，若 $I$ 是 $V$ 上的恒等算子，那么 $I$ 与 $V$ 上每个算子都可交换

# 5.72 例：偏微分算子可交换

设 $m$ 是非负整数．令 $\mathcal { P } _ { m } ( \mathbf { R } ^ { 2 } )$ 表示具有两个实自变量且次数最高为 $m$ 的实系数多项式构成的实向量空间，其带有实值函数的一般加法和标量乘法运算．于是 $\mathcal { P } _ { m } ( \mathbf { R } ^ { 2 } )$ 中的元素，是$\mathbf { R } ^ { 2 }$ 上形式如下的函数 $p$ ：

$$
p = \sum_ {j + k \leq m} a _ {j, k} x ^ {j} y ^ {k}, \tag {5.73}
$$

其中下标 $j$ 和 $k$ 可取遍每个满足 $j + k \le m$ 的非负整数值，每个 $a _ { j , k }$ 都属于 $\mathbf { R }$ ， $x ^ { j } y ^ { k }$ 表示定义为 $( x , y ) \mapsto x ^ { j } y ^ { k }$ 的 $\mathbf { R } ^ { 2 }$ 上的函数

定义算子 $D _ { x } , D _ { y } \in \mathcal { L } \big ( \mathcal { P } _ { m } ( \mathbf { R } ^ { 2 } ) \big )$ 为

$$
D _ {x} p = \frac {\partial p}{\partial x} = \sum_ {j + k \leq m} j a _ {j, k} x ^ {j - 1} y ^ {k} \quad \text {与} \quad D _ {y} p = \frac {\partial p}{\partial y} = \sum_ {j + k \leq m} k a _ {j, k} x ^ {j} y ^ {k - 1},
$$

其中 $p$ 定义如式(5.73)．因为算子 $D _ { x }$ 和 $D _ { y }$ 都只对两个变量之一求微分，而将另一个变量当作常数，所以它们得名为偏微分算子（partial differentiation operator）

算子 $D _ { x }$ 和 $D _ { y }$ 可交换，因为若 $p$ 定义如式 (5.73)，则

$$
\left(D _ {x} D _ {y}\right) p = \sum_ {j + k \leq m} j k a _ {j, k} x ^ {j - 1} y ^ {k - 1} = \left(D _ {y} D _ {x}\right) p.
$$

等式 $D _ { x } D _ { y } = D _ { y } D _ { x }$ 在 $\mathcal { P } _ { m } ( \mathbf { R } ^ { 2 } )$ 上成立，还说明了另一个更为一般的结论，那就是对于性质良好的函数，偏微分运算的顺序是无关紧要的

可交换矩阵并不很常见．例如，各元素均为区间 [−5,5] 内整数的 $2 \times 2$ 矩阵，两两共可凑出 214,358,881 对（考虑顺序），但如此多对矩阵中仅有约 $0 . 3 \%$ 是可交换的

用计算机检验得，讨论范围内的214,358,881（等于 $1 1 ^ { 8 }$ ）对 $2 \times 2$ 矩阵中，仅有 674,609 对矩阵是可交换的

下面结论说明了，两个算子可交换当且仅当它们（关于同一个基）的矩阵是可交换的
