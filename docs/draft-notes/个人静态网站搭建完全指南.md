## 五、笔记双轨同步方案

### 5.1 稳定笔记：GitHub仓库同步（推荐方式）

**方法一：Git Submodule（推荐，自动化程度高）**


# 在项目根目录，将GitHub笔记仓库作为子模块引入
git submodule add https://github.com/iron-water/Great-notes.git docs/stable-notes

# 以后更新笔记时，运行：
git submodule update --remote docs/stable-notes



这样 `docs/stable-notes/` 目录的内容会与你的 GitHub 笔记仓库保持同步。

**方法二：手动同步（更简单，适合新手）**


# 在电脑另一个位置克隆你的笔记仓库

# 每次更新网站前，手动将 .md 文件复制到 docs/stable-notes/
# 或写一个简单的复制脚本



**方法三：GitHub Actions自动拉取（全自动）**

在 `.github/workflows/sync.yml` 中配置，每次笔记仓库更新时自动触发网站重新构建（进阶，暂时可以跳过）。

### 5.2 草稿笔记：CouchDB同步

**原理**：写一个脚本，在每次 `npm run build` 之前，自动连接本地CouchDB，读取所有文档，转换为 `.md` 文件，保存到 `docs/draft-notes/`。

**第一步：安装依赖**


npm install nano    # CouchDB 的 Node.js 客户端



**第二步：创建同步脚本**

新建 `scripts/couch_sync.js`：


/**
 * CouchDB → Markdown 同步脚本
 * 运行方式：node scripts/couch_sync.js
 * 
 * 使用前请修改以下配置：
 */

const nano = require('nano');
const fs = require('fs');
const path = require('path');

// ===== 配置区（修改这里）=====
const COUCHDB_URL = 'http://anno:unknowdw221@localhost:5984';  // CouchDB连接地址
const DATABASE_NAME = 'anno';                        // 数据库名
const OUTPUT_DIR = path.join(__dirname, '../docs/draft-notes'); // 输出目录
// ==============================

const db = nano(COUCHDB_URL).db.use(DATABASE_NAME);

async function sync() {
  console.log('🔄 开始同步 CouchDB 草稿...');

  // 清空输出目录（重新生成）
  if (fs.existsSync(OUTPUT_DIR)) {
    fs.rmSync(OUTPUT_DIR, { recursive: true });
  }
  fs.mkdirSync(OUTPUT_DIR, { recursive: true });

  // 获取所有文档
  const result = await db.list({ include_docs: true });
  const docs = result.rows
    .map(row => row.doc)
    .filter(doc => !doc._id.startsWith('_')); // 过滤系统文档

  let count = 0;

  for (const doc of docs) {
    // 跳过没有内容的文档
    if (!doc.content && !doc.md && !doc.body && !doc.text) continue;

    // 获取笔记内容（兼容不同字段名）
    const content = doc.content || doc.md || doc.body || doc.text || '';

    // 获取笔记标题
    const title = doc.title || doc.name || doc._id;

    // 获取日期
    const date = doc.updated_at || doc.created_at || new Date().toISOString().split('T')[0];

    // 获取标签
    const tags = Array.isArray(doc.tags) ? doc.tags : [];

    // 生成文件名（过滤非法字符）
    const filename = title
      .replace(/[&lt;>:"/\\|?*\s]/g, '-')
      .replace(/-+/g, '-')
      .toLowerCase()
      .slice(0, 60) + '.md';

    // 生成 Frontmatter + 内容
    const mdContent = `---
title: "${title}"
date: ${date}
tags: [${tags.map(t => `"${t}"`).join(', ')}]
source: CouchDB
draft: true
---
${content}
`;

    fs.writeFileSync(path.join(OUTPUT_DIR, filename), mdContent, 'utf-8');
    count++;
  }

  // 生成草稿区首页索引
  const indexContent = `---
title: 草稿笔记
---
# 📝 草稿笔记

> 这里是我的草稿区，存放尚未整理完成的笔记。内容可能不完整，仅供参考。

共 ${count} 篇草稿

`;
  fs.writeFileSync(path.join(OUTPUT_DIR, 'index.md'), indexContent, 'utf-8');

  console.log(`✅ 同步完成！共导出 ${count} 篇草稿笔记`);
}

sync().catch(err => {
  console.error('❌ 同步失败：', err.message);
  console.error('提示：请确认 CouchDB 正在运行，并检查连接地址和密码');
  process.exit(1);
});



**第三步：配置构建脚本**

修改 `package.json`，让构建前自动运行同步脚本：


{
  "scripts": {
    "docs:dev": "vitepress dev docs",
    "docs:build": "node scripts/couch_sync.js && vitepress build docs",
    "docs:preview": "vitepress preview docs",
    "sync:couch": "node scripts/couch_sync.js",
    "sync:github": "git submodule update --remote docs/stable-notes",
    "sync:all": "npm run sync:couch && npm run sync:github",
    "deploy": "npm run docs:build && node scripts/deploy_oss.js"
  }
}

## 八、部署到阿里云OSS静态网站托管

### 8.1 创建用于托管网站的 OSS Bucket

> 
> 
> 注意：建议新建一个专门用于网站托管的桶，与存图片的桶分开。
> 
> 

1.  登录阿里云控制台 → 对象存储OSS
2.  创建Bucket：
    *   名称：`my-website`（随意）
    *   地域：**华北2（北京）**（与备案地址一致）
    *   读写权限：**公共读**
3.  进入该Bucket → **基础设置** → **静态页面**：
    *   默认首页：`index.html`
    *   默认404页：`404.html`
    *   开启：✅

### 8.2 绑定自定义域名

1.  进入Bucket → 传输管理 → 绑定用户域名
2.  填入你的备案域名（如 `www.yourdomain.com`）
3.  开启 HTTPS（申请免费SSL证书）
4.  在你的域名DNS解析中，添加CNAME记录指向OSS提供的地址

### 8.3 安装 OSS 部署工具


# 安装阿里云OSS命令行工具
npm install -D ali-oss

# 或者使用 ossutil（阿里云官方CLI）
# 下载地址：https://help.aliyun.com/document_detail/120075.html



**创建部署脚本** `scripts/deploy_oss.js`：


const OSS = require('ali-oss');
const fs = require('fs');
const path = require('path');

// ===== 配置区 =====
const config = {
  region: 'oss-cn-beijing',
  accessKeyId: process.env.OSS_KEY_ID,       // 从环境变量读取，不要硬写到代码里！
  accessKeySecret: process.env.OSS_KEY_SECRET,
  bucket: 'my-website',                       // 你的网站桶名
};
const DIST_DIR = path.join(__dirname, '../docs/.vitepress/dist');
// ==================

const client = new OSS(config);

async function uploadDir(localDir, ossDir = '') {
  const files = fs.readdirSync(localDir, { withFileTypes: true });
  for (const file of files) {
    const localPath = path.join(localDir, file.name);
    const ossPath = ossDir ? `${ossDir}/${file.name}` : file.name;
    if (file.isDirectory()) {
      await uploadDir(localPath, ossPath);
    } else {
      await client.put(ossPath, localPath);
      process.stdout.write(`✅ ${ossPath}\n`);
    }
  }
}

async function deploy() {
  console.log('🚀 开始部署到阿里云OSS...');
  await uploadDir(DIST_DIR);
  console.log('🎉 部署完成！');
}

deploy().catch(err => {
  console.error('❌ 部署失败：', err.message);
  process.exit(1);
});



**设置环境变量**（Windows PowerShell）：


$env:OSS_KEY_ID="你的AccessKey ID"
$env:OSS_KEY_SECRET="你的AccessKey Secret"
