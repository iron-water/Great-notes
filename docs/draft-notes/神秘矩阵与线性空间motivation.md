# SB1.3.2 [线性组合] (Linear combination )
> V中一个向量组v的线性组合是形如$$a_1v_1+\cdots+a_nv_n$$的向量，其中$a_1$, ... ,$a_n$∈$F$.

那么问题来了，V是什么呢，答案是vector的有效活动范围：
# SB1.1 [向量空间] (Vector space)
> 满足向量加法成阿贝尔群，标量乘法成幺半群(?)且赠送分配律的神秘集合称为向量空间，在上文中简记为V.[^1]

在开头我们称呼$v$君为向量的原因就是他能在向量空间里面活动，这其实是一个了不起的能力，我们看定义就知道不是所有集合都能当向量空间的。也就是说，$v$君的手下向量在一个性质非常好的开挂空间里面训练并发动技能，相应的，在$R$上的向量空间称为实向量空间，而在$C$上的向量空间称为复向量空间。$v$君现在升级后就是在复向量空间上的向量组，不过在哪里不是很重要，文中统一简记$R$和$C$为$F$.
