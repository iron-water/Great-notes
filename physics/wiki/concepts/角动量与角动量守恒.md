## Core Intuition

角动量是动量 $\times$ 力臂：$\mathbf{L} = \mathbf{r} \times \mathbf{p}$。$\boldsymbol{\tau} = d\mathbf{L}/dt$ 是对 $\mathbf{F} = d\mathbf{p}/dt$ 的矢量直接推导，**不依赖刚体假设**。合外力矩为零 → 角动量守恒。

## Key Theorems

### 质点角动量
$$\mathbf{L} = \mathbf{r} \times \mathbf{p} = m\mathbf{r} \times \mathbf{v}$$

### 刚体定轴转动的角动量
$$L = I\omega$$

### 角动量定理
$$\boldsymbol{\tau} = \frac{d\mathbf{L}}{dt}$$

### 角动量守恒定律
$\sum\boldsymbol{\tau}_外 = 0$ → $\mathbf{L} = \text{常矢量}$（包括大小和方向）。

对定轴转动：$I_1\omega_1 = I_2\omega_2$。手握哑铃旋转时收臂——$I \downarrow \Rightarrow \omega \uparrow$。

### 与动量定理的对偶
$$\mathbf{F} = d\mathbf{p}/dt \quad\longleftrightarrow\quad \boldsymbol{\tau} = d\mathbf{L}/dt$$
两者都来自 $\mathbf{F} = m\mathbf{a}$，但 $\boldsymbol{\tau} = d\mathbf{L}/dt$ 不需要刚体约束条件。

## Common Misconceptions

1. 角动量守恒不要求系统是刚体——可以变 $I$ 但保持 $L$ 不变。
2. 平移运动的质点对某参考点也有角动量。角动量不是转动体特有的——它只依赖于是否选定了参考点。
