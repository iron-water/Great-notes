## Core Intuition

以轨迹自身为"坐标轴"：切向 $\boldsymbol{\tau}$（沿运动方向）+ 法向 $\mathbf{n}$（指向曲率中心）。把加速度拆成"改变速率"和"改变方向"两个独立分量。

## Key Theorems

### Frenet 标架
- $\boldsymbol{\tau} = d\mathbf{r}/ds$，单位切向
- 曲率 $\kappa = |d\boldsymbol{\tau}/ds|$，曲率半径 $\rho = 1/\kappa$
- 法向 $\mathbf{n}$：$d\boldsymbol{\tau}/ds = \kappa\mathbf{n}$

### 加速度分解
$$\mathbf{a} = \frac{dv}{dt}\boldsymbol{\tau} + \frac{v^2}{\rho}\mathbf{n}$$

**推导**：$\mathbf{v} = v\boldsymbol{\tau}$，对时间求导并利用链式法则 $d\boldsymbol{\tau}/dt = (d\boldsymbol{\tau}/ds)(ds/dt) = \kappa\mathbf{n}\,v$。

### 曲率半径公式（平面曲线 $y = f(x)$）
$$\rho = \frac{(1 + y'^2)^{3/2}}{|y''|}$$

### 圆周运动特例
- 匀速：$a_\tau = 0$，$a_n = v^2/R$（恒定）
- 变速：$a_\tau = R\alpha$，$a_n = \omega^2 R$

## Common Misconceptions

1. $\boldsymbol{\tau}$ 的导数 $d\boldsymbol{\tau}/dt$ 为何垂直于 $\boldsymbol{\tau}$？因为 $|\boldsymbol{\tau}| = 1$ 是常数，对任何参数求导都得垂直关系。
2. 法向加速度恒指向曲率中心（轨迹凹侧），不是指向圆心（除非是圆周运动）。
3. 法向加速度**不做功**——$\mathbf{a}_n \perp \mathbf{v}$，所以法向力不改变速率大小。
