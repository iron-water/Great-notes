## Core Intuition

力矩是"力产生转动效果"的度量——不是力的大小决定转动，而是力 × 力臂。$\tau = I\alpha$ 是 $\mathbf{F} = m\mathbf{a}$ 的转动版本。

## Key Theorems

### 力矩定义（对转轴）
$$\tau = \mathbf{r} \times \mathbf{F}$$
定轴转动中只关心沿轴方向的分量：
$$\tau_z = \pm F_t R = \pm FR\sin\varphi$$

### 转动定律
$$\tau = I\alpha$$

**推导**：对每个质点 $F_{t,i} = m_i a_{t,i} = m_i r_i\alpha$，两边乘 $r_i$：$\tau_i = m_i r_i^2 \alpha$，求和得 $\tau = (\sum m_i r_i^2)\alpha = I\alpha$。

### 力矩的功与功率
$$dW = \tau d\theta, \quad P = \tau\omega$$

## Common Misconceptions

- 力过转轴 → 力矩为零 → 无论力多大都不产生转动效果。
- 刚体定轴转动中只有切向分力产生力矩，法向分力（指向轴心）力矩为零。
